TÍNH NĂNG CHƯƠNG
- Cho phép đổi tên chương sau khi đã tạo/phác thảo.
- Nút Lên / Xuống để đổi thứ tự chương trong cùng Phần.
- Cho phép chuyển chương giữa “Ngoài Phần” và các Phần khác.
- Không thay đổi/mất nội dung chương khi di chuyển.
- Sau mỗi lần di chuyển, order được chuẩn hóa 0..n-1 để tránh trùng thứ tự.
- Tạo chương mới dùng max(order)+1, tránh trùng order sau khi từng xóa chương.
- Hoạt động bằng nút/select nên dùng được trên điện thoại, không lệ thuộc kéo-thả chuột.

SỬA QUÊN MẬT KHẨU KHO
- Sau khi đặt lại Kho, tab Bảo mật hiển thị banner trạng thái ngay tại khu vực Kho.
- Có trạng thái Thành công / Lỗi rõ ràng và aria-live.
- Phân biệt: đặt lại Kho đã thành công nhưng bước đồng bộ sau đó chưa hoàn tất.
- Không còn tình trạng thông báo nằm tận cuối panel khiến người dùng tưởng thao tác không có phản hồi.

CÁCH ÁP DỤNG (WINDOWS / POWERSHELL / CMD)
1) Giải nén hai file .mjs vào THƯ MỤC GỐC của repo HuyenButCac.
2) Mở Terminal tại thư mục HuyenButCac.
3) Chạy:

   node apply-hbc-chapter-vault-patch.mjs
   npm test
   npm run build

4) Nếu cả test và build đều qua, kiểm tra thay đổi:

   git diff

5) Sau đó commit/push như bình thường:

   git add src/features/projects/projectsService.ts src/stores/projectsStore.ts src/components/projects/ProjectsView.tsx src/components/auth/AccountPanel.tsx src/tests/projectsService.test.ts
   git commit -m "feat: reorder chapters and show vault reset result"
   git push

KHÔI PHỤC NẾU CẦN

LƯU Ý
- Script kiểm tra các “mốc” trong source trước khi sửa. Nếu repo đã thay đổi nhiều so với main ngày 2026-09-03,
  script sẽ dừng thay vì sửa nhầm.
- Có thể chạy script áp dụng nhiều lần; nếu bản vá đã tồn tại, script sẽ bỏ qua.
